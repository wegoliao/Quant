B18 · Sharpe 信賴區間

它解決什麼

B08 樣本量門檻 擋住了「用 11 筆日報酬算 Sharpe」。門檻是 20 筆。

然後樣本到了 20 筆，門檻打開，Sharpe 印出一個數字。

那一刻比之前更危險。N/A 沒有人會拿去下注；3.13 會。而 20 筆的 Sharpe 3.13，和 0 在統計上分不出來。

門檻不是「這個數字現在可信了」，門檻是「這個數字現在最低限度可以計算了」。 中間的差距，就是這個積木。

契約

sharpe_standard_error(curve) -> {
    "sharpe", "stderr", "low", "high", "n", "covers_zero"
} | None

低於門檻回傳 None —— 這個積木永遠不能替一個頁面正在拒絕顯示的數字化妝。

公式（Lo 2002，IID 假設）

在報酬的原始頻率上：

SE(SR) = sqrt( (1 + SR² / 2) / n )

然後用同一個 √252 年化：

daily  = mean(returns) / stdev(returns)
annual = daily * sqrt(252)
se_daily  = sqrt((1 + 0.5 * daily**2) / n)
se_annual = se_daily * sqrt(252)
ci = (annual - 1.96 * se_annual, annual + 1.96 * se_annual)

數字有多可怕

n = 20、年化 Sharpe 3.13：

daily SR  = 3.13 / √252 = 0.197
SE(daily) = √((1 + 0.5 × 0.197²) / 20) = 0.226
SE(年化)  = 0.226 × √252 = 3.58
95% 區間  = 3.13 ± 1.96 × 3.58 = −3.90 ~ 10.15

標準誤比估計值本身還大。區間涵蓋 0。

翻譯成人話：以目前樣本，這個 Sharpe 還無法和運氣區分。

需要多少樣本才收斂

固定 SR = 3.13（年化），看 SE 怎麼縮：

n（日報酬）SE（年化）95% 區間下界
203.58−3.90
602.07−0.93
126（半年）1.43+0.33
252（一年）1.01+1.15
504（兩年）0.71+1.73

要到大約半年，區間下界才離開 0。 要到一年，才能說「這個策略的 Sharpe 大於 1」。

這張表值得印在任何報 Sharpe 的頁面旁邊。

頁面上要怎麼寫

不是把 CI 藏在附註，是取代點估計的地位：

Sharpe 3.13，標準誤 ±3.58（Lo 2002，n=20）。
95% 區間 −3.90 ~ 10.15。
區間涵蓋 0 —— 以目前樣本，這個 Sharpe 還無法和運氣區分。
樣本越長區間才會收斂；在那之前，點估計是最容易被誤讀的一個數字。

陷阱

陷阱 1：IID 假設不成立。 Lo 的公式假設報酬獨立同分布。真實報酬有自相關（尤其是流動性差的標的），自相關為正時真實 SE 更大。所以這個區間是樂觀的下限，不是保守估計。要寫明。

陷阱 2：用 CI 當作「還可以」的藉口。 「區間上界有 10.15，所以說不定很好」是誤用。區間涵蓋 0 的正確結論是不知道，不是「可能很棒」。

陷阱 3：只對合計算，不對各策略算。 單一策略的樣本和合計一樣長，但波動更大 → Sharpe 更不穩。各條線都該有自己的區間。

陷阱 4：Deflated Sharpe 是另一回事。 這個區間處理的是樣本雜訊。如果你試了 200 組參數才挑出這一組，還有選擇偏誤要扣，那是 DSR 的工作。兩個要一起做，見 Gemini 目錄的 GB10。

一句話

N/A 保護你不被小樣本騙。 門檻打開之後，保護你的是區間。 中間那段沒有人守的時間，是大部分過度自信的來源。
