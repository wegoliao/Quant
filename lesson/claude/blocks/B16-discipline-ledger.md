# B16 · 紀律帳

## 它解決什麼

Owner 的原話：**我沒有遵守策略。我看情勢不對，賣掉一堆策略沒叫我賣的賺錢部位。給我看我的成績，也給我看策略的成績。**

這是每一個「有系統但會手動介入」的人最想知道、卻幾乎沒有人在量的東西：**我的直覺到底是在加分還是扣分？**

## 為什麼這題可以精確回答

一般的反事實需要模型。**這一題不需要。**

股票已經賣掉了。「如果沒賣，現在值多少」不是預測，是一個查表題：

```
同樣股數 × 最新官方收盤 − 同一套出場費稅
```

沒有假設、沒有參數、沒有模型風險。

## 契約

```python
discipline_ledger(fills, prices, asof) -> {
    "rows",                   # 每筆平倉 + 分類 + 反事實
    "directed_realized",      # 有「出」訊號才賣的已實現
    "discretionary_realized", # 卡片仍寫「抱」時賣的已實現
    "strategy_open_pnl",      # 那些若沒賣，現在的未實現
    "decision_value",         # 實收 − 若持有到今天 = 決策價值
}
```

## 分類規則

一筆賣出是**策略指示**，若且唯若：

```python
存在一筆 signal_history 紀錄，其 (strategy_id, stock_code) 相同、
signal 的動作是「出」、且 asof_date <= 賣出日
```

否則是**自主決定**。

注意 `signal.strip("()*")` —— 卡片可能印出 `(出)`、`出*` 這種裝飾過的字形，分類要看動詞不看字形。詳見 [`B17`](B17-two-source-realized.md) 旁邊的同一個教訓。

## 決策價值

```python
decision_twd = proceeds_twd - hold_value_twd
```

- **正** = 賣掉比抱著好（躲過下跌）
- **負** = 賣早了（少賺）

兩種用**同一把尺**。這一點必須寫在頁面上，因為一個只標示「賣錯」不標示「賣對」的表，會變成一個道德工具而不是量測工具。

## 真實產出的形狀（去識別）

| | 筆數 | 已實現 |
|---|---:|---:|
| 策略指示 | 少數 | 小額 |
| **自主決定** | **多數** | **絕大部分** |
| 若沒賣，現在的未實現 | | 較低 |
| **決策價值** | | **正** |

在一個實際案例裡，**96% 的已實現來自策略沒叫他賣的部位**，而決策價值是正的。

但逐筆看，好壞都有：最好的一筆和最差的一筆差了一個數量級，最差那筆是**賣早了**（賣出後續漲）。

## 三個一定要寫在頁面上的但書

**1. 這是記分，不是評判。**
沒有這句話，這張表會被讀成「你不該手動介入」或「你的直覺很準」。它兩者都不是。

**2. 樣本不足。**
十幾筆自主賣出，不足以證明直覺長期優於策略。這個帳的價值在於**它會一直記下去**。

**3. 決策價值會隨時間變。**
今天賣對的，下個月可能變成賣早了。這張表是「截至今日」的快照，不是最終判決。用 `asof` 標明。

## 陷阱

**陷阱 1：把「策略沒說話」當成「策略叫你抱」。**
卡片上沒有「出」不等於它主動要你續抱 —— 可能只是那天沒更新。分類要基於**明確出現的訊號**，不是基於缺席。這是為什麼規則寫成「存在一筆出訊號」而不是「不存在出訊號就是抱」。

**陷阱 2：反事實用進場價而不是實際成本。**
`hold_pnl = hold_value − cost_twd`，其中 `cost_twd` 必須是 FIFO 對沖後的**實際帳面成本**，不是策略卡的進場價。用卡片進場價會把選股差異混進決策價值裡。

**陷阱 3：暫計出場混進來。**
[`B15`](B15-provisional-exit.md) 的暫計成交沒有真實成交價，把它放進決策價值等於在評估一個沒發生的決策。

## 這個積木為什麼重要

大部分「系統交易 + 人工覆蓋」的組合，從來沒有人算過覆蓋本身的貢獻。結果是兩種失敗：

- 覺得自己很準 → 覆蓋越來越多 → 系統變成裝飾
- 覺得自己會壞事 → 完全不敢動 → 系統的盲點沒人補

**量出來之後，這個爭論就結束了** —— 剩下的只是等樣本。
